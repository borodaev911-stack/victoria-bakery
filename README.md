# Виктория — сайт-витрина

Локальная первая версия по согласованному ТЗ. React, TypeScript и Vite. Одна страница без сервера, базы данных или форм сбора данных.

## Запуск

```sh
npm install
npm run dev -- --port 5173
```

Открыть http://127.0.0.1:5173/.

```sh
npm run build
npm run preview
```

Готовая статическая сборка находится в `dist/`. GitHub Actions публикует сборку на GitHub Pages при обновлении ветки `main`. Адрес: https://borodaev911-stack.github.io/victoria-bakery/.

## Контент

- `src/content.ts` — работы, описательные названия, сгруппированные ракурсы и разрезы.
- `src/App.tsx` — страница и утверждённый рассказ Виктории.
- `src/style.css` — адаптивное оформление и анимация.
- `public/images/` — оптимизированные WebP из фотографий пользователя; исходники в Downloads не изменены.
- `public/fonts/`, `src/fonts.css` — локальные шрифты Cormorant Garamond, Manrope, Bad Script (Google Fonts).
Оригиналы фотографий и внутреннее ТЗ не включены в репозиторий.

Названия работ редакционные, описания основаны на видимых деталях. Состав, вес, стоимость и наличие не заявляются.

## Что осталось предоставить

В `src/content.ts`, объект `site`:

- `maxUrl` — реальная ссылка для связи. Пока пустая: кнопка в контактах отключена с пояснением, ссылки шапки ведут к этому разделу.
- `heroVideo` — адрес согласованного видео рук с тестом и выпечки в духовке. Пока пустой: первый экран использует настоящую фотографию торта. Подключённое видео воспроизводится без звука с повтором; есть постер и управление движением.

Сайт адаптирован к уменьшенной анимации, допускает остановку движения. Галерея: Escape, клавиши-стрелки, кнопки, свайп; удержание и возврат фокуса и позиции страницы.

Перед публикацией: проверить названия работ, добавить контакт, согласовать видеоматериал и выбрать домен/хостинг. Полная видеосцена из ТЗ ещё не создана.
